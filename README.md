# Portafolio-de-anal-tica
Este repositorio reúne una colección de proyectos enfocados en analítica de datos, donde aplico herramientas y técnicas para la limpieza, transformación, análisis y visualización de datos. Incluye el uso de tecnologías como SQL, Power BI y Excel para generar insights accionables y apoyar la toma de decisiones basada en datos.
